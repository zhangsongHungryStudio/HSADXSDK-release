# HSADXSDK

HSADXSDK iOS advertising SDK binary distribution, version 1.2.55.

## Requirements

- iOS 13.0+
- Xcode 13.0+
- CocoaPods 1.10+

## Architectures

- arm64 (iOS Device)
- arm64, x86_64 (iOS Simulator)

## Getting Started

Add the following to your `Podfile`:

```ruby
pod 'HSADXSDK'
```

Then run:

```
pod install
```
